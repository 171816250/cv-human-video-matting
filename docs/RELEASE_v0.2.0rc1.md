# 0.2.0rc1 答辩候选说明

本候选版基于a6230b0继续优化，已有版本完整备份。当前为本地候选版本，未作远端正式Release。

## 使用体验

网页默认处理全部帧，直接设置声音、背景色与输出尺寸。处理时显示进度，当前浏览器会话可停止运行中的任务；模型加载和单帧推理不强制中断，返回后响应停止。排队任务暂不支持撤回。摄像头和视频批处理串行使用推理资源，避免同时执行多个推理任务争用显存。

每次网页任务生成独立目录，包含媒体、透明帧ZIP（适用时）和运行报告。所有产物成功后才发布目录，取消或报告失败不会留下半成品。命令行Ctrl+C释放视频资源并回收FFmpeg；输出进度可以通过--no-progress关闭。

## 评测与交付

schema3报告记录软件版本、Git状态、源码指纹、输入/输出SHA256、实际输出规格及元数据采集时间。网页提供报告下载。summarize生成离线中文HTML或JSON，只将已记录条件相同的报告分组；旧报告单独标记。默认缓存权重没有自动核验哈希，仍需在正式实验中固定和核验。

package_release.py从已提交的HEAD打包源码，选入指定验证材料，生成Git历史恢复包和SHA256清单。已跟踪文件未提交、输出目录已存在或证据路径冲突时拒绝打包。用户自己的未跟踪文件不会自动进入源码包。
