# v1.0.0 发行说明

版本日期：2026-10-23。标签对应提交、正式发布状态和可下载附件以 [Gitee 发行页](https://gitee.com/ciyechenchen/cv-human-video-matting/releases)实际记录为准。本地标签、分支推送或候选 ZIP 本身不等于平台发行版。

## 本版本提供什么

v1.0.0 整理了自然场景人像视频抠像的本地处理与交付流程。默认使用 RVM MobileNetV3，可通过网页或命令行上传、处理视频，选择纯色、图片、虚化、alpha、黑底前景、左右对比及透明 PNG 序列。常规视频先生成 FFV1 无损中间文件，再导出 H.264/yuv420p MP4；原片首条音轨可转为 AAC 并按处理长度截断。透明结果为带 alpha 的 PNG 序列或 ZIP，没有音轨。

独立 GPU 实时工作区使用 FastAPI/WebSocket，可选择浏览器摄像头或本地视频，显示 FPS、往返延迟和服务器处理时间。它与 Gradio 视频处理页面分别启动；默认只监听本机，只接收一个活动会话，每次保持一帧在途。网络部署与新显卡环境均需在实际机器上验证。

工程交付还包括：

- 输入参数、设备、文件路径与编解码器预检，任务进度、取消和失败回滚。
- 边缘羽化、形态学后处理与 EMA/自适应时间平滑，默认关闭，按素材选择。
- 离线 RVM 模型包、来源与逐文件 SHA256 校验，以及输入输出和源码身份报告。
- 服务器安装、数据备份、恢复及更换租赁机器时的交接工具和说明。
- 已有报告的离线汇总、私人案例同帧截图与清单复核工具。

## 相比历史候选版本的整理

本次包含实验性 Depth Anything V2 Small 本地后端及资源准备/校验流程，CLI 和 Gradio 可在准备好独立本地模型后启用相对远近标签。模型运行时不自动下载权重，不执行远程模型代码。独立 WebSocket 实时工作区尚未接入深度标注。

修复了 BiRefNet 预测结束后向 `MattingResult` 传入不支持的 `state` 参数所引发的报错；回归覆盖 tensor/list/tuple 输出、原始尺寸恢复、颜色归一化、alpha 数值范围及纯色/透明渲染。这个修复不等于已完成 BiRefNet 真实权重推理或画质评估。

本次统一版本标识，更新当前交付状态，保留历史 rc 发行说明及其原始验证口径。Gitee Go 的离线测试配置已经准备，平台构建尚未完成验收。

## 安装与首次运行

完整环境步骤见[安装与验收](INSTALLATION.md)，常用命令见 [README](../README.md)。建议为批处理与实时 GPU 服务使用各自独立环境，按目标系统、显卡和驱动安装匹配的 PyTorch/TorchVision，不复制旧机器的虚拟环境。

首次使用需准备：

1. Python 与声明的运行依赖，以及可用的视频编码器。
2. 已核实来源的 RVM 缓存或完整离线模型包；不要将 Git LFS 指针当作真实权重。
3. 有权处理的视频和背景素材。合成示例可用 `scripts/create_smoke_video.py` 生成，真实人物视频需另行准备。
4. 在项目根目录运行 `python app.py doctor`，确认环境与模型准备情况，再按 README 启动本地网页或命令行处理。

`Start-Demo.cmd` 面向已准备好的基础演示环境；实时 GPU 入口为 `Start-Realtime.cmd`，依赖准备、端口与浏览器限制见[实时说明](REALTIME.md)。可选深度资源按 [Depth Anything 说明](DEPTH_ANYTHING.md)另行安装和校验。离线模型包不包含 Python、CUDA 驱动或所有可选模型，详见[离线模型说明](OFFLINE_MODEL.md)。

## 验证记录与适用范围

2026-10-23 本轮完整工程回归为 **724 passed、2 skipped、46 warnings，耗时 58.01 秒；核心包语句覆盖率 91.03%（2599/2855）**。测试环境为 Windows、Python 3.10.16、pytest 8.4.2 和 CPU 运行依赖；两项跳过与 Windows 目录符号链接权限有关，测试报告及覆盖率材料随验证附件保存。

BiRefNet 的 7 项离线回归全部通过。本轮没有下载或冒烟运行真实 BiRefNet 权重，替身模型回归不构成真实模型效果验收。

此前已有 RVM CPU 离线网页和 GPU WebSocket 的真实模型合成素材运行记录，条件见[历史 rc3 验证](VALIDATION_v0.2.0rc3.md)与[历史 rc4 验证](VALIDATION_v0.2.0rc4.md)。Depth Anything V2 Small 的真实权重在本机 CPU 合成帧上运行成功，详见[深度验证记录](VALIDATION_DEPTH_ANYTHING_2026-10-02.md)。单帧或合成素材基准不能推导真人画质、持续实时帧率或公网使用效果。

## 当前限制

- BiRefNet 与 Depth Anything V2 Small 为可选实验后端。BiRefNet 本次接口修复使用替身模型回归；Depth Anything 尚缺真人对比与连续视频速度验收。
- Near/Mid/Far 来自当前人物遮罩范围的相对深度统计，不表示米数，不支持多人独立测距。较大的深度刷新间隔可能造成标签滞后。
- 实时工作区当前只允许一个活动会话；多用户并发、录制导出及深度标注不在该入口的本版本范围。
- 真人发丝、弱光、遮挡、快速动作、长视频及跨浏览器摄像头仍需按授权素材和目标硬件留存验收记录。
- 无损中间视频会占用额外磁盘空间；输出按输入名义帧率写出，变帧率素材需检查音画同步。
- 远程摄像头访问依赖浏览器安全上下文、网络及实际部署配置；仅上传源码或启动监听不等于完成远程验收。
- 尚未形成可验证的 Gitee LFS ≥1GB 上传结果。普通 Git 仓库大小、LFS 实际用量、平台额度、发行版数量及社区指标应分别依据平台证据填写。

## 附件与校验

本次拟公开的内容为冻结 Git 提交生成的源码 ZIP、验证附件、SHA256 清单与附件说明，具体文件名和提交号以实际发行页为准。源码 ZIP 不附模型权重、运行环境、私人案例、服务器机器记录或本地完整 Git 历史。模型及其配套源码分发时应保留各自的来源、许可、署名和清单。

下载后先按 SHA256 清单核对附件，将源码 ZIP 解压到新目录，按 README 重新准备依赖、模型并执行环境检查。验证附件中的报告须按日期、源码身份、输入类型、模型和设备解释，不将历史报告直接当作本机验收结果。

`scripts/package_release.py` 保持原有本地候选包语义，会生成 `candidate.zip`、完整可达历史的 `repository.bundle` 和 `remote_release=false` 清单。它可用于团队本地备份，但不创建 Gitee Release；完整历史 bundle 不随本次公开发行附件发布。实际交付与备份迁移步骤见[答辩指南](DEFENSE_GUIDE.md)和[服务器交接](RENTED_GPU_HANDOFF.md)。

项目源码采用 MulanPSL-2.0；RVM、Depth Anything、BiRefNet 等外部模型和源码遵守各自许可，项目许可证不替代上游模型许可。问题反馈请附软件版本、设备环境、复现步骤和经过脱敏的错误信息，通过[仓库 Issues](https://gitee.com/ciyechenchen/cv-human-video-matting/issues)提交。
