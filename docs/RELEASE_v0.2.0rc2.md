# 0.2.0rc2 本地答辩候选版本

本轮在0.2.0rc1备份基础上改进离线部署、时间平滑、视频编码和失败保护。尚未发布远端Release，不应视为已完成真人素材和目标机器验收。

## 交付变化

- 可从现有缓存导出RVM源码、预训练权重、LICENSE与SHA256清单；使用本地源码加载，拒绝包内文件变更，不回退下载。报告记录加载身份，支持空缓存网络请求拦截试运行。
- 时间平滑增加adaptive选项，根据相邻原始alpha变化降低历史权重，减少移动边界拖影；原EMA保留，平滑默认关闭。网页和CLI均可设置模式和阈值，实时缓存会随这些参数和模型配置变化重建。
- 视频中间编码改为FFV1/Matroska，避免先mp4v再H.264的额外损失；最终仍为H.264/AAC。需要更多临时磁盘空间。
- CLI/UI在建模前共用预检；已知帧数提前解码结束时报错；未知总帧数在报告中标为未核验，不伪装成完整性检查通过。指定CUDA失败会报错，只有auto允许自动选择CPU。
- CLI先生成媒体与报告再发布，普通异常可回滚旧结果；透明输出保留原有备注，失败撤销本次帧。保护输入、背景、检查点及离线模型包目录，防止被输出或报告覆盖。多文件发布不承诺断电事务语义。
- Doctor核对声明的依赖版本并实际检查FFV1写读，不把“能导入”当作“满足安装要求”。

## 实验边界

合成移动遮罩实验中，自适应平滑相较EMA显著减少历史残留；静态噪声实验中的均方误差接近原EMA。参数为blend=0.75、motion_threshold=0.15，固定随机种子2026。详细数字、复现脚本和媒体保存在交付证据中，不据此宣称真人质量提升比例。

实际RVM离线试运行使用已缓存的MobileNetV3权重，GPU运行三次、CPU运行一次，源素材为合成视频。它验证代码、权重、推理、合成、导出和报告链路，不验证真人抠像质量或持续实时速度。

本机已有环境的NumPy、OpenCV、Pillow、pytest、tqdm低于当前安装声明，Doctor如实返回ready=false。没有修改或升级全局环境；自动化测试和模型运行结果不能替代独立干净环境的安装验收。

## 恢复与下一阶段

升级前备份位于工作区`backups/before-v0.2.0rc2-84dc246/`，包含逐文件校验的工作区快照与Git历史；原v0.2.0rc1交付物保留。新候选包包含当前源码、Git历史、测试证据、离线RVM模型包和使用说明。

下一阶段仍需完成经授权的真人案例、持续摄像头演示、目标机器独立环境安装及长视频性能/音画同步验收；相对深度和BiRefNet须各自实测后才能纳入正式演示。
