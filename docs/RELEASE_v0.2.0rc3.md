# 0.2.0rc3 本地答辩候选版本

本轮补齐上一版“程序在原环境能运行，但独立安装环境未验收”的缺口，重点是安装、启动和网页处理链路。升级前保留 `backups/before-v0.2.0rc3-c4f85f2/`，含 457 个文件的校验快照与 Git 恢复包；原 rc2 候选包保留。

## 交付变化

- 新建项目 `.venv`，使用 Python 3.10.16 / Torch 2.5.1+cpu / TorchVision 0.20.1+cpu。原有全局 Python、Conda 与 DLF 环境未升级。
- 基础 RVM 网页、BiRefNet / MiDaS 可选依赖及开发测试工具分开。完整 CPU 清单冻结 81 项运行包，安装来源及环境检查记录随证据保留。
- `Start-Demo.cmd` 使用项目解释器，自动查找唯一有效离线 RVM 包，先校验再启动本地网页。显式路径按调用目录解释，默认配置能从其他目录找到；多个模型包需明确选择。
- 网页离线模式仅提供包内模型，并关闭深度标注；接口也拒绝请求其他模型或深度下载。关闭 Gradio 后台统计。
- Doctor 按实际启用功能核对依赖，增加 Torch/TorchVision 配对检查，支持 `--requirements` 指定完整清单。
- 新增 `verify_local_demo.py`：启动真实服务，上传样例、运行 RVM、下载视频与报告，校验帧数、各项参数、模型、源码与文件哈希，最后回收自己的服务。日志保留成功或失败细节。

## 使用与验证

当前工作区可双击 `Start-Demo.cmd`。迁移电脑或解压交付包后，按[安装说明](INSTALLATION.md)新建 `.venv`；包内不复制本机环境，也不包含 Python、CUDA 驱动或全部依赖安装文件。运行依赖安装需要联网或事先准备匹配的 wheel 文件；模型推理可使用附带的离线 RVM 包。

本版完整工程回归为 **579 项通过、1 项跳过**，核心代码覆盖率 **89.97%**。跳过项是本机无创建符号链接权限的保护测试；39 条警告来自依赖弃用提示。详细环境、真实网页运行、输入范围和证据位置见[验证记录](VALIDATION_v0.2.0rc3.md)。

## 尚待验收

工作区暂无可用于本次验收的已授权真人原片及标准 alpha 标注。现有合成视频验证工程流程，不证明真人发丝、弱光、遮挡、快速动作的质量。目标答辩电脑、持续摄像头、浏览器播放和长视频音画同步仍需单独实测；本轮新环境是 CPU 组合，不能替代 CUDA 安装验收。可选 BiRefNet 与 MiDaS 未纳入这一离线演示。

此版本为本地候选包，未创建远端 Release；申报中的社区及发布指标应以平台记录为准。
